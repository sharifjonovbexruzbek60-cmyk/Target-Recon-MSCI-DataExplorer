## Overview

This repository records methodology and high-level observations from a security-learning exercise. It intentionally avoids credentials, private data, exploit payloads, and instructions that could enable unauthorized access.

## Safety and scope

Only perform reconnaissance with explicit authorization and within a documented scope. Respect rate limits, stop on signs of instability, and report suspected weaknesses through the target's official disclosure channel.
